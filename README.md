# 星遇同频 · VRCX 提醒

[星遇同频](https://vrcc.cc/match/) 的 VRCX 脚本。装上以后，VRCX 左边会多一个「星遇同频」：

- 星遇同频的提醒弹在 VRCX 里：没戴头显时在电脑右下角，戴着时按 VRCX「通知」里的设置弹
- 看和你星轨相交的星、互相连上的星
- 给你所在的地图打分，地图榜上没有的由你添加
- 加入 VRChat 中文社区的 VRChat 群组

这里是源码，公开出来方便大家看它做了什么。`vrcx.js` 和 [vrcc.cc/match/vrcx.js](https://vrcc.cc/match/vrcx.js) 是同一个文件，两边不一样时以 vrcc.cc 上的为准。

## 安装

只从星遇同频下载：在「我的资料 → 在 VRCX 里提醒」里，按网页上的三步做。别人发给你的 custom.js 不要装。

## 检查手上的文件

在「我的资料 → 在 VRCX 里提醒」点「检查我的 custom.js」，选你的文件。文件只在你的浏览器里比对，不上传；改过的、旧版的都会告诉你。

## 它读什么、发什么

从 VRCX 读：

- VRChat 开没开、戴没戴头显、VRCX 的通知设置：决定弹不弹、弹在哪
- 你所在的地图：只取地图 ID，不取房间号
- 你的好友和你加入的群组：只在本机用来显示「已是好友」「已加入」，不发出去

发给星遇同频（`https://vrcc.cc/api/match`）：

| 什么时候 | 发什么 |
| --- | --- |
| 连接 | 连接码 |
| VRCX 启动时一次，之后 VRChat 开着时每分钟左右一次 | 提醒令牌、脚本版本、收到哪条提醒了 |
| 打开「星遇同频」 | 提醒令牌、你所在地图的 ID（看它在地图榜上的情况） |
| 打分 | 提醒令牌、地图 ID、分数 |
| 断开 | 提醒令牌 |

在本机存：提醒令牌和几个已读标记（VRCX 的 localStorage，前缀 `vrcc-vrcx-`）。

不做的：不读 VRCX 的登录信息，不替你向 VRChat 发任何东西，不读电脑上的文件，不从网上加载代码，收到的内容只当文字显示。加好友、加群组是打开 VRCX 自己的窗口，由你自己点。

## 安全

- 连接码 10 分钟内有效、只能用一次。只填在你自己的 VRCX 里，不要发给别人。
- 提醒令牌只能读你的提醒、星轨相交和互相连上，能做的只有给地图打分、断开自己。
- 每次新连上，星遇同频都会在站内通知你。不是你本人操作的，去「我的资料 → 在 VRCX 里提醒」断开。
- 限次和防滥用都在服务器上，不靠这个脚本。

发现安全问题，请在本仓库的 Security 页私下报告，不要开公开 issue。
