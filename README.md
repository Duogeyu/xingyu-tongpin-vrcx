# 星遇同频 · VRCX 提醒

[星遇同频](https://vrcc.cc/match/) 的 VRCX 脚本。装上以后，VRCX 左边会多一个「星遇同频」：

- 星遇同频的提醒弹在 VRCX 里：没戴头显时在电脑右下角，戴着时按 VRCX「通知」里的设置弹；错过的在「最近的提醒」里补看
- 看和你星轨相交的星、互相连上的星（在线的好友排前面）
- 看你所在地图的图和地图榜上的分，直接打分、写一句短评；地图榜上没有的由你添加
- 加入 VRChat 中文社区的 VRChat 群组

这里是源码，公开出来方便大家看它做了什么。`vrcx.js` 和 [vrcc.cc/match/vrcx.js](https://vrcc.cc/match/vrcx.js) 是同一个文件，两边不一样时以 vrcc.cc 上的为准。

## 安装

只从星遇同频下载：在「我的资料 → 在 VRCX 里提醒」里，按网页上的三步做。别人发给你的 custom.js 不要装。

## 检查手上的文件

在「我的资料 → 在 VRCX 里提醒」点「检查我的 custom.js」，选你的文件。文件只在你的浏览器里比对，不上传；改过的、旧版的都会告诉你。

## 它读什么、发什么

从 VRCX 读：

- VRChat 开没开、戴没戴头显、VRCX 的通知设置：决定弹不弹、弹在哪
- 你所在的地图：只取地图 ID，不取房间号
- 你的好友和谁在线、你加入的群组：只在本机用来显示「已是好友」「在线」、把在线的排前面、决定显不显示「加入」，不发出去
- VRCX 存着的地图缩略图：只在本机显示，不发出去

发给星遇同频（`https://vrcc.cc/api/match`）：

| 什么时候 | 发什么 |
| --- | --- |
| 连接 | 连接码 |
| VRCX 启动时一次，之后 VRChat 开着时每分钟左右一次 | 提醒令牌、脚本版本、收到哪条提醒了 |
| 打开「星遇同频」，开着时换了地图 | 提醒令牌、你所在地图的 ID（看它在地图榜上的情况） |
| 打开「最近的提醒」 | 提醒令牌、看到了哪一条（记在你的账号上，按钮上的数字跟着消） |
| 打分 | 提醒令牌、地图 ID、分数，写了短评的还有短评 |
| 断开 | 提醒令牌 |

在本机存：提醒令牌和几个已读标记（VRCX 的 localStorage，前缀 `vrcc-vrcx-`）。

不做的：不读 VRCX 的登录信息，不替你向 VRChat 发任何东西，不读电脑上的文件，不从网上加载代码，收到的内容只当文字显示。加好友、加群组、看地图是打开 VRCX 自己的玩家、群组、地图窗口，只在你点的时候。

## 安全

- 连接码 10 分钟内有效、只能用一次。只填在你自己的 VRCX 里，不要发给别人。
- 提醒令牌能读的：你的提醒（最近一天）、星轨相交（用不了时的原因）、互相连上、你所在地图在地图榜上的样子。能做的：给地图打分并带一句短评（和网页地图榜一样经过检查）、把星轨相交和最近的提醒标成看过、断开自己。
- 每次新连上，星遇同频都会在站内通知你。不是你本人操作的，去「我的资料 → 在 VRCX 里提醒」断开。
- 限次和防滥用都在服务器上，不靠这个脚本。

发现安全问题，请在本仓库的 Security 页私下报告，不要开公开 issue。

## 一起改

欢迎提 issue 和 PR。

- 这里只有 VRCX 里的这一段。要服务器配合的（新的数据、新的接口），先开 issue 说想做什么。
- 试改过的版本：放进 `%AppData%\VRCX\custom.js`，重启 VRCX，用你自己的星连上。网页「检查」会说它「可能被改过」，这是正常的。
- 上面「不做的」那几条要守住；`SITE` 和开头、结尾的两行标记不要改；版本号 `V` 由我们合并时改。
- 合并以后随星遇同频下一次上线发出去，大家会在 VRCX 里收到「有新版本」。
- 提交的改动按 MIT 协议授权。
